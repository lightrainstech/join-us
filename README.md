# Join Lightrains

This is a simple exercise to streamline the hiring process. We would love people with prior experience with Git and some contributions to Open Source projects.

Be as descriptive as you want. Committing individual steps will earn you extra points; in fact, everything you do on GitHub will.


## How to apply?

 1. Fork this repository.
 2. Create a new branch in your fork for your answers, e.g. `answers/<your-github-username>`. Don't commit to `master`.
 3. Read the questions in `questions.md`.
 4. Create a new file named `answers/<your-github-username>.md` and write your answers there. Code may go in the same file or in separate files inside a folder `answers/<your-github-username>/`.
 5. Once you've finished, submit a Pull Request from your branch to this repository's `master` branch. Mention the role you're applying for in the PR description.

*If you have any doubts, please open an issue in this very repository.*


## How we evaluate

- **Correctness**: does the code do what the question asks, including edge cases?
- **Readability**: clear names, sensible structure, comments where they help.
- **Reasoning**: explain your approach and its trade-offs, e.g. time and space complexity.
- **Git hygiene**: small, focused commits with meaningful messages, and a clean PR.
- **Tests**: not required, but welcome.
